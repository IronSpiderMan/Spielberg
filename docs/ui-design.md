# Spielberg UI 视觉系统

## 产品与方向

本项目是 React / Arco Design / Tauri 本地漫剧制作工作室，主要使用者是需要连续编辑脚本、角色、镜头和生成素材的创作者。页面由现有 React 状态切换，不新增路由或业务状态。

原界面存在暖色、深蓝、紫色提示词样式叠加；导航权重较高；项目操作抢占页面主操作；编辑面板、列表和配置均采用相似卡片层级。此次以浅色工作区、低对比导航、单一蓝色操作强调建立统一语言，保留媒体预览的深色画布。

## 统一规则

- `src/design-system.css` 是应用主题入口，集中提供语义颜色、字号、间距、圆角、状态与响应式规则。
- 主色 #315DCC；背景 #F7F8FA；表面 #FFFFFF；边框 #E2E5EA；正文 #202733；次级文字 #596577；辅助文字 #687588。
- 页面标题 24px，区段标题 16–18px，卡片标题 14px，正文和列表 13px，标签 12px，元信息 11px。
- 采用 4px 间距体系，常用 8 / 12 / 16 / 24 / 32px；控件、面板、弹窗分别使用 6 / 8 / 12px 圆角。
- 只有弹窗等浮层使用柔和阴影；主体依靠分隔线和表面对比。反馈过渡为 180ms，保留 reduced-motion 支持。
- 优先突出当前页面的主要操作，全局项目操作使用低权重按钮；危险操作保留文字、确认和悬浮反馈。

## 页面实现

- 工作台：连续的真实项目概况，显示剧集、场景、角色及已选视频数；保留三步制作流程。脚本场景采用标题条，必填场景描述与选填帧描述分区。
- 图片生成：参数与预览形成双栏，较窄内容区自动转为单栏。
- 剧集：场景采用连续列表；宽屏将状态与操作放在同一行，窄屏允许换行。
- 资产：筛选栏集中呈现，缩略图为主体；卡片操作降噪，保留分页、用途追踪、回收站和清理。
- 角色、Prompt、任务、项目：统一媒体、标题、正文和元信息层级。项目卡片与角色新增入口支持 Enter / Space 操作。
- 模型配置：服务说明和字段分栏呈现，使用分隔线代替多重卡片；窄屏堆叠。
- 欢迎页、弹窗、抽屉、空状态、加载骨架：共享同一字体、配色和控件体系。

`src/ui.tsx` 提供 PageHeading、ProjectSummary 和 PageLoading。功能样式统一在 main.tsx 导入，避免懒加载页面时改变主题优先级。

## 验证

执行过实现 → 截图检查 → 微调 → 生产构建检查。测试使用隔离的模拟 Tauri IPC，不操作真实项目或生成服务。

- `npm run build`：TypeScript 和 Vite 生产构建通过。
- `STRICT_UI=1 node scripts/qa/ui-audit.cjs`：覆盖 1920、1440、1280、1024、768、390px，共 96 项布局检查；包含主要页面、图片生成、场景编辑、抽屉和弹窗。
- 关键行为：脚本发布、未保存保护、角色生成、设置保存、Prompt 复用、项目切换。
- 原有 asset-management、asset-assignment、role-assets 回归通过，覆盖资产分页、用途跳转、回收站、备份默认选项、搜索重试、角色素材设置等。
- 实际截图输出位于 `/tmp/spielberg-ui/`，其中 `report.json` 记录布局检查结果。运行脚本需要可用的 Playwright，可使用 `PLAYWRIGHT_PATH` 指定外部安装。

本次不修改后端、API、数据模型、认证和权限，也未增加依赖。原生文件选择器、真实模型调用和桌面视频解码仍需在 Tauri 环境中验证。
