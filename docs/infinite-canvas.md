# 画布场景

画布是场景的一种创建方式。打开「剧集」，点击「新建场景」，填写名称并选择：

- 默认方式：使用原有场景编辑器设置画面、描述和生成参数。
- 画布方式：在独立画布中连接图片、音频和视频节点创作。

两种场景位于同一剧集下，使用同一套排序、复制、删除与场景视频合并流程。创建方式在创建后固定，每个画布场景有独立草稿。原来的全局画布入口和左侧项目资源栏已移除。

## 节点和连接

在画布空白处右键，选择添加图片、音频、视频或便签节点，节点落在右键点击的画布位置。「添加节点」按钮也可打开菜单，便于触屏操作。

图片、音频和视频节点可从项目素材中选择对应类型的文件，也可上传本地文件。素材选择支持搜索与分页，上传后进入现有资产库。音视频节点提供播放控件。

从图片、音频、视频或便签节点右侧的输出端口拖到视频节点左侧的输入端口（显示预览线），或依次点击两个端口，建立有方向的参考连接。支持图片 → 视频、音频 → 视频、视频 → 视频、便签 → 视频；便签内容会与视频描述合并作为提示词。图片节点也有输入端口，支持图片或便签输入；音频没有输入端口。从输入端拖到空白处可添加上游节点并自动连接，从输出端拖到空白处可添加下游节点。禁止自连接、重复连接和循环依赖。Esc 取消连接，点击连线后使用「移除选中」删除。

图片节点仅显示图片主体，悬停或选中时显示标题、替换、清除和图生图操作；可直接拖动图片移动节点。拖动卡片标题移动节点，拖动空白处或滚轮平移；Ctrl / ⌘ + 滚轮缩放，右下角也可缩放和适应画布。新增、修改、删除和拖拽支持撤销重做。

## 图片生成

空图片节点点击「文生图 / 图生图」，填写描述、画幅和尺寸。无参考图片使用文生图（`t2i`）；连接上游图片或节点已有图片时，使用图生图（`i2i`），参考当前图片及上游图片，便签合并到提示词。已有图片再生成时创建右侧结果节点并连接，保留原图。生成沿用项目模型配置和资产库，保存画布后保留参数及结果引用。

## 视频生成

在视频节点中填写描述、时长、画幅与输出尺寸，然后点击「生成视频」。

- 无输入连接：使用现有文生视频请求。
- 有输入连接：将上游素材按图片、视频、音频分组，使用现有全能参考请求（`ref2v`）。最多 9 张图片、3 个视频与 3 个音频，与已有工作台一致。
- 上游视频节点必须已有素材或生成结果，空节点不能作为参考。

点击生成按钮才提交任务，连线不会自动提交。请求带当前 `scene_id`，继续复用现有模型配置、后台任务、资产入库和场景视频候选记录。空视频节点的生成结果填入当前节点；已有视频的节点再生成时，在右侧创建并连接新结果节点，保留原素材和参数。新结果可继续连接到下游视频节点。点击「设为场景视频」选择用于剧集合并的版本；已有场景视频可通过剧集的现有视频合并流程输出成片。剧集批量生成遇到画布场景时会提示进入画布操作视频节点。

## 保存、引用和兼容

「保存画布」保存节点、素材 ID、连线、便签、生成参数和视角。场景名称也可在顶部修改。画布模式隐藏主导航与页面顶栏，画布占满整个屏幕，仅保留浮动的返回、名称、保存、节点操作与缩放控件。离开页面或关闭浏览器时提醒未保存的修改；生成完成后仍需保存画布，保留节点对应的结果。生成素材本身会立即进入现有资产库。

已保存的素材节点纳入资产用途，防止素材被误删。移除或清除节点素材后，需要保存画布才能解除该引用。复制画布场景会复制草稿与素材引用，删除场景或剧集会解除相应画布引用，不删除素材文件。不同场景的保存版本与引用互相独立。

保存通过 `revision` 防止多窗口覆盖。若出现版本冲突，当前草稿保留在页面上，可先导出 JSON 再重新加载。JSON 导出仅包含布局、参数和资源 ID，不包含素材文件；当前没有 JSON 导入界面。

数据库版本 10 增加场景 `creation_mode`、`scene_canvases` 与 `scene_canvas_sources`。旧版非空项目画布自动迁移为第一集下的「原项目画布」场景；项目没有剧集时会创建「画布创作」剧集。旧节点、连线、布局和保存版本保留。新建画布使用新的媒体节点和端口连接方式。画布随 SQLite 项目备份恢复，不存储素材绝对路径。

## API

| 接口 | 请求 | 返回 |
| --- | --- | --- |
| `POST /api/v1/projects/{project_id}/episodes/{episode_id}/scenes` | `{title, description?, creation_mode?: "default" \| "canvas"}` | 场景，含 `creation_mode` |
| `POST /api/v1/actions/canvas/load` | `{project_id, scene_id}` | `{draft, revision}` |
| `POST /api/v1/actions/canvas/save` | `{project_id, scene_id, draft, revision}` | `{draft, revision}` |

`draft` 包含 `version: 1`、`nodes`、`edges` 和 `viewport`。新节点类型为 `image`、`audio`、`video` 和 `note`，素材通过可选的 `ref_id` 引用。视频节点保存 `prompt`、`duration`、`ratio` 和 `size`。旧版节点类型仍可读取并保存。节点坐标允许负值，缩放范围 20%–200%，每张画布最多 500 个节点与 1000 条连线。加载与保存仅允许当前项目内的画布场景。
