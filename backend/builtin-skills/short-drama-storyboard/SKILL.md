# 短剧分镜与关键帧 · Spielberg

把当前项目的故事拍清楚：每个镜头有叙事作用、可读动作、合理时长和可信的前后衔接。沿用用户选择的画风、画幅和制作方式。静态漫剧可用关键帧、配音和剪辑节奏完成表达，不强求每镜运动。

这是 Spielberg 内置适配版。剧本、资产、分镜和素材均由现有项目工具读写，不创建本地文件，不运行脚本，也不依赖其他技能。

## 进入任务

1. 读取当前项目大纲、相关设定文档、时间线、人物关系和目标剧集的现有剧本、分镜。通过真实查询取得 ID，长正文沿 `next_offset` 读完。具体读取与保存方式见 [项目工具与交付格式](references/spielberg-tools.md)，首次读写项目时读取该文件。
2. 用户要求制作或修改分镜时，完成对应项目内容的保存；只是讨论方案、比较镜头或明确要求仅在对话中输出时，保持为讨论。局部修改只改指定镜头，保留其他剧情、对白、镜序、引用和已生成素材。
3. 依据剧本确定观众什么时候知道什么、主要人物如何行动、关键转折与结尾悬念。已有剧本的事实和原话不因分镜而改写；真正影响剧情的缺口说明为待定，普通摄影选择直接按上下文完成。
4. 检查已有角色、地点和道具资产及图片。需要确认身份、造型或构图时，用 `inspect_image` 查看真实图片；未查看的图片不能声称已视觉核验。缺图列出所需画面，继续完成可用的文本分镜，不伪造素材 ID 或图片路径。

## 设计镜头

复杂对白、交接道具、群戏、揭示或连续动作，读取 [镜头设计与连续性](references/shot-craft.md) 的相关章节。

- **先目的后摄影**：明确这一镜让观众看懂的变化，再选景别、机位、运镜和切点。新信息、人物决定、反应、权力或空间变化都可成为切镜依据。固定机位也是有效选择，不为变化而移动摄影机。
- **动作有边界**：用“起点 → 主要动作 → 终点”写出可见状态。对白、必要停顿与反应应放得下；过载时拆镜或调整时长，不能靠“快速完成”掩盖。对白保留原文；无录音时将时长注明为文本估计。
- **站位有依据**：同场多镜先确定门、桌、窗等固定锚点与人物关系，再投影为每个机位下的前后景和画面左右。写清人物看向谁、哪只手拿着什么，以及道具的交接路径。前镜终点应能成为后镜起点；跳时空、蒙太奇或有意重复明确标注。
- **形象保持一致**：复用已确认的角色造型、服装、地点布局、道具状态、画风和光线描述；需要变化时落实变化发生的镜头。参考图分别说明控制身份、地理、构图还是风格，不能让风格图替换人物身份。
- **关键帧是一瞬间**：首帧只写动作开始前可见的构图、姿态、视线、持物与光线，不提前画出终点才出现的证物或伤痕。需要明确落点时再给尾帧。单张提示词不塞入“先……再……”的完整动作链。
- **按实际能力制作**：已指定生成模型时读取当前渠道和能力，分别规划叙事镜长与生成片段时长。Spielberg 的 `StoryboardClip` 规划结构每个片段总长不超过 15 秒。场景级一镜到底按所选模型的时长范围校验，并将连续片段作为同一镜头的动作段落。

## 交付与检查

逐镜保留编号、来源场次或剧本短引文、叙事目的、时长、景别/机位、运镜、起止状态、动作、原文对白/声音、首帧提示词及参考素材；尾帧和排除项按需增加。统一画幅和提示词语言，沿用用户偏好；未指定时使用中文。

保存到本集分镜头剧本时，把这些信息放入五列 CSV 的“描述”中。需要“AI 分镜与片段制作”时使用 `episodes.storyboard.clips`。用户要求制作叙事场景时，使用 `scenes` 归并有连续性的片段，在场景层写共享设定。格式、字段与示例见工具参考。

完成前核对：原文动作和对白是否被落实，反转是否提前泄露；相邻镜头的视线、方向、造型、双手和持物是否衔接；镜长是否容纳声音与动作；图片引用是否真实可用；只修改了要求的范围。保存后重新读取结果，报告实际保存位置、镜头数、预计总时长及真正缺少的素材。

分镜和提示词本身不代表已生成图片或视频。用户只要求分镜时完成规划与保存；用户已经要求出图、视频或配音时，沿用其授权和已有渠道，通过真实生成工具执行并核对结果，不重复索要已给出的确认。
